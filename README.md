# Nice Gadgets — Phone Catalog

A modern, responsive e-commerce web application for browsing and purchasing mobile phones, tablets, and accessories. Users can explore product categories, filter and sort items, view detailed product specifications, and manage their shopping cart and favorites.

## Technologies Used

- **React** — component-based UI architecture
- **TypeScript** — static typing for safer and scalable code
- **React Router** — client-side routing and URL-synced filtering/pagination
- **SCSS (Sass) / CSS Modules** — modular, responsive styling across mobile, tablet, and desktop viewports
- **Swiper** — interactive touch sliders for banners and product galleries
- **Vite** — fast project bundling and local development server
- **LocalStorage** — persistent state for the shopping cart and favorite items

## Getting Started

)
Follow these instructions to set up and run the project locally on your machine:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/adadiada/phone-catalog
   cd your-phone-catalog-repo
   ```

2. **Install dependencies:**

   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the project locally:**

   ```bash
   npm start
   # or
   yarn start
   ```

## Features

- **Product Catalog & Filtering:** Browse phones, tablets, and accessories with dynamic sorting (by age, title, or price) and pagination.
- **Detailed Product Pages:** View high-resolution image galleries, available color/capacity variants, tech specs, and recommended items.
- **Shopping Cart & Favorites:** Add or remove products, adjust item quantities, and calculate total order costs with data saved in `LocalStorage`.
- **Responsive Layout:** Adaptive grid design optimized for mobile (320px), tablet (640px), and desktop (1200px+) screens.
